# 🔐 Secret Diary — твой личный дневник под защитой PIN-кода

> «Только ты знаешь код — только ты читаешь записи»

**Secret Diary** — это набор консольных приложений для ведения личного дневника с защитой PIN-кодом.  
Программа шифрует все записи, требует ввод PIN-кода при каждом запуске и автоматически блокируется после бездействия.

## 🚀 Особенности
- 🔒 Защита PIN-кодом (4-6 цифр).
- 📝 Добавление, редактирование и удаление записей с датой и временем.
- 🔍 Поиск по ключевым словам.
- 🗂️ Категории записей (личное, работа, идеи, другое).
- 🔐 Шифрование записей (XOR или AES — где реализовано).
- ⏰ Автоматическая блокировка после 5 минут бездействия.
- 📤 Экспорт записей в CSV и JSON (требуется PIN).
- 🎨 Цветной вывод в терминале.
- 💾 Автосохранение в JSON-файл (`secret_diary.json`).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python secret_diary.py`                |
| Go         | стандартная библиотека               | `go run secret_diary.go`                |
| JavaScript | Node.js, `fs`, `readline`            | `node secret_diary.js`                  |
| Java       | стандартная библиотека               | `javac secret_diary.java && java secret_diary` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `serde`, `serde_json`, `chrono`      | `cargo run`                             |
| Ruby       | `json`, `date` (стандартные)         | `ruby secret_diary.rb`                  |
| PHP        | стандартная библиотека               | `php secret_diary.php`                  |
